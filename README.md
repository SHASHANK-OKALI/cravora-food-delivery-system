## 🌟 About CRAVORA

**CRAVORA** is a modern food delivery web application designed to provide a smooth and engaging online food ordering experience.

Users can explore restaurants, discover food items, search and filter menus, manage their cart, place orders, track orders, save favorite foods and manage their profile.

The application focuses on modern UI/UX design, responsive layouts, interactive components and practical frontend development concepts.

---

## ✨ Features

### 🏠 Home Page

- Attractive hero section
- Featured restaurants
- Popular food items
- Food categories
- Promotional offers
- Call-to-action sections
- Modern responsive design

### 🏪 Restaurant Discovery

- Restaurant cards
- Restaurant images
- Cuisine information
- Ratings
- Delivery time
- Availability status
- Restaurant details

### 🍕 Food Menu

- Food images
- Food names
- Categories
- Prices
- Descriptions
- Ratings
- Add to Cart functionality

### 🔎 Search & Filtering

Users can:

- Search restaurants
- Search food items
- Filter by category
- Filter by price
- Sort by rating
- Sort by popularity

### 🛒 Shopping Cart

- Add food items
- Increase quantity
- Decrease quantity
- Remove items
- Clear cart
- Dynamic price calculation
- Subtotal calculation
- Delivery charge
- Total amount

### ❤️ Wishlist

- Add foods to favorites
- Remove favorites
- Dedicated wishlist interface
- Wishlist data persistence

### 📦 Food Ordering

Users can:

- Enter customer information
- Enter contact details
- Add delivery address
- Select payment method
- Review order
- Submit order

### 🚚 Order Tracking

Order status interface includes:

- Order confirmed
- Food preparation
- Out for delivery
- Delivered

### 📜 Order History

Users can view:

- Previous orders
- Ordered items
- Quantities
- Total amount
- Order status
- Order dates

### 👤 User Profile

Profile interface includes:

- Personal information
- Saved information
- Order history
- Favorite foods
- Account-related options

### 💳 Payment UI

Includes a frontend payment interface supporting:

- Card payment UI
- UPI payment UI
- Cash on Delivery UI
- Payment method selection

> This is a frontend payment interface and does not process real payments.

CRAVORA includes a modern dark mode designed to maintain a consistent visual experience across the application.

The admin interface provides UI for:

- Food management
- Order overview

- Dashboard statistics

Important user data is persisted using browser LocalStorage, including:
