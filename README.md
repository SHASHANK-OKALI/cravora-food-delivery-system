# 💜 Cravora — Food Delivery System

> **Crave it. Tap it. Enjoy it.**

A modern, responsive food-delivery web application built with **React + Vite + CSS + React Icons**. Cravora is designed as a polished portfolio project inspired by real-world food ordering platforms.

## ✨ Features

- Premium Cravora purple/navy UI with light and dark mode
- Responsive desktop, tablet and mobile layouts
- Hero landing page with offers and stats
- Restaurant discovery
- Food categories and featured dishes
- Search food and restaurants
- Category, price and rating/popularity filters
- Shopping cart with quantity management
- Wishlist / favorites
- Checkout form with validation
- Payment method UI
- Order confirmation and order history
- Order status/progress UI
- Profile dashboard
- Admin dashboard demo
- LocalStorage persistence for theme, cart, favorites and orders
- Smooth hover effects and responsive interactions

## 🚀 Run locally

Requirements: Node.js and VS Code.

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal, normally `http://localhost:5173/`.

## 🛠️ Build for production

```bash
npm run build
npm run preview
```
